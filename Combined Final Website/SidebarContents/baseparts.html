Baseparts

Baseparts are the fundamental building blocks for modeling. They represent physical objects that can be placed in the game world and interacted with by players, scripts, and physics.

Types of Baseparts

  • Part: A simple cube or rectangular block, the most common building element.
  • Wedge: A sloped block useful for ramps and angled surfaces.
  • Cylinder: A round block often used for pillars or wheels.
  • Ball: A spherical part, useful for round objects or physics experiments.
  • Mesh: A unique part that uses an exported mesh from other modeling software. They cannot be union!

Common Properties

  • Colour: Simply changes the colour. Unions need to have "base colour" enabled to fully change its colour.
  • Cast Shadow: Allows shadow to be casted by the object. Invisible objects does not cast shadows unless it is set to a ridiculous amount (Studio Bug).
  • Transparency: Changes the transparency of the object.
  • Anchored: Ensures object cannot be moved physically. Can change its position via scripts.
  • Locked: Cannot be selected by user's cursor but can still block cursor selection. Mainly used in studio mode..
  • Can Collide: Controls if object/players can pass through it.
  • Can Touch: Allows object to detect if it has been 'touched' by any baseparts. Works with 'Can Collide' disabled and used for script events.
  • Can Query: Determine if raycasts can pass through them.

Models

Models is a parent grouping used to contain multiple instances of baseparts and special objects

They can contain

  • RootPart: Any object that is chosen to be a primary part (Found in the Model's properties). This changes the pivot point of the model and they are highlighted in gray.
  • Humanoid: A special object that gives a model humanoid properties. This is how a player is created.

Best Practices

  • Use Anchored for static structures like buildings.
  • Group parts into Models for easier manipulation.
  • Apply Materials (wood, metal, glass) for realistic appearance.
  • Keep part counts optimized to avoid performance issues in large games.
Note: Baseparts are the core of Roblox building. Every complex model or structure ultimately relies on Baseparts as its foundation.
