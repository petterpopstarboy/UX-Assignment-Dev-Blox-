Workspace

The Workspace is the root container in Roblox Studio where all 3D objects that appear in the game world are stored. It acts as the main environment where parts, models, and scripts interact.

Key Features

  • Parts and Models: All physical objects in your game are placed inside Workspace.
  • Scripts: Scripts can reference Workspace to access or modify objects.
  • Visibility: Workspace is accessible to both the server and the client.

Server vs Client

Roblox uses a client-server model. The Workspace exists on both sides:

  • Server: Handles game logic, physics, and security.
  • Client: Handles rendering and user interface.

Communication between server and client is done using RemoteEvents and RemoteFunctions.

Best Practices

  • Organize objects into folders for clarity (e.g., “Enemies”, “Items”).
  • Use CollectionService tags to manage groups of objects.
  • Keep Workspace clean by moving non-visual data into ReplicatedStorage or ServerStorage.
Note: Certain objects such as GUI and Sounds do not rely on workspace to work.
